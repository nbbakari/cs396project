How retrieval works
  1. The server calls CAMPD’s emissions/apportioned/annual endpoint with the filters above, and (optionally) facilities/attributes for location and dates, then merges the two by facility, unit and year.
  2. The EPA API key is read from the server’s environment and sent only in a request header to the EPA. It never appears in pages, URLs, logs or the database.
  3. The response is kept as a CSV file, validated, and shown on the review page with every rejected or flagged row. Nothing is imported until you approve.
  4. The query parameters, endpoint, date and record counts are stored as the dataset’s provenance.
  5. Approved data is saved in this computer’s database only; it is not sent to the team’s shared database.
