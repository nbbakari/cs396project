epaData

epaData collects, validates and stores U.S. power-sector emissions data published by the Environmental Protection Agency, and makes it searchable, comparable and downloadable. Every record can be traced back to the retrieval or upload it came from, and every row that was rejected during validation is kept in a data-quality report.

Phase 1 (this release) covers data management: retrieval, upload, validation, storage, search, display and download. Phase 2 will add environmental evaluation with TRACI characterization factors and a multi-indicator scoring model.

Data sources

EPA Clean Air Markets Program Data (CAMPD)

Annual, unit-level operating and emissions data reported by power-sector units under the Acid Rain Program (since 1995) and related programs: operating time (hours), gross load (MWh), steam load (1000 lb), heat input (MMBtu), and CO2, SO2 and NOx mass (short tons), with fuel types, control technologies, program codes and facility location.

{{ source_counts.get('api', 0) }} API retrieval(s) · campd.epa.gov

User-uploaded files

CSV or Excel files in the CAMPD annual emissions layout, e.g. from CAMPD Custom Data Download. Each file is kept as received, validated row by row, and imported only after approval.

{{ source_counts.get('upload', 0) }} upload(s)

EPA TRACI characterization factors Phase 2

Factors that convert emitted mass into environmental-impact indicators (e.g. global warming, acidification, smog formation).

Planned additional sources

EPA eGRID (plant capacity and electricity benchmarks), EPA NEI (PM and additional pollutants), and EPA WebFIRE / AP-42 (emission factors).
