TRACI impact assessment

What the selected emissions could do to the environment and to health. Each pollutant's mass is converted to kilograms and multiplied by EPA's TRACI factor for each effect it contributes to, such as climate change, acid rain, fine particles and smog. Each effect is reported in its own “equivalent” unit: the amount of a reference pollutant that would have the same effect.

How the numbers are calculated
  1. Filter the CAMPD records. {{ counts.records | num }} unit-year(s) match: 
    {{ analysis.search.describe_filters() }}
  2. Convert short tons to kilograms. mass_kg = mass_short_tons × {{ short_ton_kg }}
  3. Match each pollutant to its TRACI air-emission factor (CF), by exact name: CO₂ = CARBON DIOXIDE, SO₂ = SULFUR DIOXIDE, NOx = NITROGEN OXIDES (not nitrogen dioxide, which TRACI lists separately).

  4. Calculate each category separately. Impactc = Σ mass_kgi × CFi,c Categories are never added together, because each has its own equivalent unit.
