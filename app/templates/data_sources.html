Where the data in this system comes from and how it is retrieved.

EPA Clean Air Markets Program Data (CAMPD)

Emissions, operating and compliance data for regulated power plants, published by the U.S. Environmental Protection Agency.

  • Access: the CAMPD API and bulk-data downloads; the API key is kept on the server only.
  • Granularity used: annual records, one per unit (boiler or turbine) per reporting year.
  • Measures: operating time ({{ meaning('operating_time') }}), gross load ({{ meaning('gross_load') }}) and steam load ({{ meaning('steam_load') }}), heat input ({{ meaning('heat_input') }}), CO₂ ({{ meaning('co2_mass') }}), SO₂ ({{ meaning('so2_mass') }}) and NOx ({{ meaning('nox_mass') }}) mass in short tons, and control equipment (pollution-removal equipment).
campd.epa.gov
